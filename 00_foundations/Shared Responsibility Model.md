### AWS Responsibility: Security **of** the Cloud
- Hardware / AWS Global infrastructure  
- Regions, Availability Zones (AZ), Edge Locations  
- Software (AWS-managed services)  
- Compute, Storage, Database, Networking infrastructure

### Customer Responsibility: Security **in** the Cloud
- Client data encryption, integrity, and authentication  
- Server-side encryption (file system / data)  
- Networking protection (encryption, integrity, identity)  
- OS, Network, and Firewall configuration  
- Platform, Applications, Identity & Access Management (IAM)  
- Customer Data management
