Default aurora mode is **Single-Master** mode
One **R/W** and 0+ **R/O** Replicas
Cluster endpoint is used to write and read endpoint for load balanced reads
Failover take the time to promote a replicat to **R/W**
Multi-Master mode = **all** instances are **R/W**
