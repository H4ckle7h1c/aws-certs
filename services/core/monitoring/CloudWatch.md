### Key Components
#### Metrics

- Quantitative data related to AWS products, applications, or other sources (via CloudWatch Agent).
- **Examples:** CPU usage, RAM usage, disk I/O, network traffic.
#### Logs

- Collects and stores log data from AWS services, applications, or on-premises servers.
#### Events

- Captures events generated by AWS services or custom schedules.
- Used to trigger automated actions or workflows.

---
### Core Concepts
#### Namespace

- Logical container for monitoring data.
- AWS services send data to default namespaces like `AWS/EC2`.
- Organizes related metrics under a common label.

#### Metric

- A collection of time-ordered data points representing a specific measurement.
- Not strictly tied to a single service; e.g., CPU utilization metric may come from multiple sources.

#### Datapoint

- A single measurement within a metric, consisting of:
    - **Timestamp:** When the measurement was taken
    - **Value:** The metric’s numeric value

#### Dimension

- A key/value pair that helps separate datapoints within the same metric.
- Examples: `InstanceId`, `InstanceType`
- Allows filtering and aggregation of datapoints by dimension.

#### Alarm

- A rule that performs actions based on metric values crossing thresholds.
- Used to automate responses like notifications or scaling actions.
