EC2 instances have [[eni]] : elastic network interfaces 
ENI :
- MAC address 
- Primary IPv4 address 
- 0 or more secondary IP address 
- 1 elastic IP address per private IPv4 
- 0 or more IPv6 addresses 
- Security Groups 
- Source/Destination check
Assigning a new elastic IP address loses the original public IPv4 address
