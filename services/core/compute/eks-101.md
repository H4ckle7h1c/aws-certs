EKS : Elastic Kubernetes Service 

Definition : AWS Managed Kubernetes -> opensource & cloud agnostic

Run : AWS, Outpost, EKS Anywhere, EKS Distro

Control planed is managed by AWS and scales and run on multiple AZs 
Integrates with AWS Services, ECR, ELB, IAM, VPC
etcd distributed across AZs
Nodes -> self managed, managed node groups, fargate pods
