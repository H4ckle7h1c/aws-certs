
---

### 🧩 Definition  
Fault tolerance is the **property of a system that enables it to continue operating properly** even if one or more of its components fail.

In short = Operate Through Failure

---
### 🎯 Goal  
- Ensure systems **operate through failure**  
- Avoid **total outages** by seamlessly handling component failures  

---

### ⚙️ How?  
- Design systems to **minimize downtime**  
- Automatically detect failures and **switch to redundant components**  
- Ensure the switch causes **no disruption to users**

---

### 🆚 Example  

| Scenario                  | Description                                                                |
| ------------------------- | -------------------------------------------------------------------------- |
| ❌ Without Fault Tolerance | A server crashes → system swaps to another → users experience **downtime** |
| ✅ With Fault Tolerance    | A server crashes → system auto-fails over → **no outage**                  |
